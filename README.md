# Viral Studio AI — protótipo web
Hospede em um serviço Node.js 20+ (não funciona apenas no GitHub Pages). Comando: npm start. Configure APP_PASSWORD e pelo menos uma chave: ANTHROPIC_API_KEY, GEMINI_API_KEY, GROQ_API_KEY, OPENROUTER_API_KEY. Modelos podem ser alterados por CLAUDE_MODEL, GEMINI_MODEL, GROQ_MODEL, OPENROUTER_MODEL. Não habilite cobrança se deseja evitar custos. O servidor tenta os provedores na ordem acima; as cotas e disponibilidade dependem deles. Use HTTPS e uma senha forte; não publique suas chaves. A hospedagem gratuita pode ter limites.
Abra o endereço no Chrome Android. Em configurações, informe APP_PASSWORD. Teste o exemplo sem chave. Mantenha a tela aberta durante a exportação em tempo real. Projetos ficam no armazenamento local do navegador.
Limitações: renderização isométrica procedural em canvas, não vídeo generativo 3D arbitrário; cinco cenários. Exportação de animação sem áudio, voz apenas na prévia. Cortes manuais com texto sobreposto e áudio original quando suportado. Sem transcrição automática, download do YouTube, publicação automática ou análise de melhores momentos. Exporte e publique manualmente após conferir. Compatibilidade MediaRecorder depende do navegador. Não testado em Android real. Não há garantia de uso ilimitado de APIs nem de hospedagem grátis.
